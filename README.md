V8 Search Engine – Jupiter

A custom full-stack search engine built from scratch to demonstrate fast query processing, custom algorithmic indexing, and lightweight data persistence.

 Features
- Custom Search & Indexing: Powered by Java and custom Data Structures & Algorithms (DSA) for fast query lookups and result retrieval.
- Lightweight Storage: Uses SQLite3 for structured, efficient storage of indexed records.
- Responsive Interface: Clean web frontend built with HTML, CSS, and JavaScript for real-time query input and dynamic result rendering.

 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Java, Data Structures & Algorithms (DSA)
- Database: SQLite3
